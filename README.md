# هوبا بديل سيري

مساعد صوتي لأندرويد (9 وأعلى) بيتحكم في التليفون بالكلام، بأوامر عربي مصري أو إنجليزي.
المشروع ده مكتوب من الصفر بـ Kotlin، ومفيهوش أي كود أو تصميم من تطبيق تاني.

## إزاي تطلّع ملف APK

### الطريقة (أ): من غير Android Studio، عن طريق GitHub
1. اعمل حساب على github.com لو معندكش، وسوّي Repository جديد (Private أحسن).
2. ارفع محتوى فولدر `Hoba` كله (ومعاه فولدر `.github` المخفي).
3. افتح تبويب **Actions** وشغّل **Build APK** (Run workflow)، أو هيشتغل لوحده بعد الرفع.
4. لما يخلص (5-10 دقايق تقريبًا) افتح التشغيلة ونزّل **Hoba-APK** من تحت.
5. فك الضغط هتلاقي `app-debug.apk`، انقله للتليفون وثبّته (فعّل "التثبيت من مصادر غير معروفة").

### الطريقة (ب): Android Studio
افتح فولدر `Hoba` في Android Studio، استنى الـ Sync، وبعدها
**Build ← Build Bundle(s) / APK(s) ← Build APK(s)**. الملف بيطلع في `app/build/outputs/apk/debug/`.

## إعداد التطبيق على التليفون
1. افتح التطبيق وادّي الإذنين (الميكروفون، والاتصال/جهات الاتصال).
2. اضغط "تفعيل خدمة هوبا" وفعّلها من إعدادات إمكانية الوصول.
3. **أندرويد 13 وأعلى:** لو زرار التفعيل رمادي، روح لـ إعدادات ← التطبيقات ← هوبا ← النقط التلاتة (⋮) ← **السماح بالإعدادات المقيّدة**، وارجع فعّل الخدمة.
4. هيظهر زرار 🎤 عايم. ضغطة = أمر واحد، ضغطة طويلة = استماع مستمر.

## ملاحظات
- التعرف على الصوت بيتم عن طريق خدمة التعرف الصوتي اللي على التليفون (غالبًا خدمة جوجل)، وجودتها بتتحسن مع الاتصال بالإنترنت.
- الأوامر محددة (مش فهم حر زي سيري). الأوامر موجودة في `Commands.kt` وتقدر تزوّد عليها.
- لو التطبيقات مفتحتش لما تقول "افتح ...": بعض إصدارات أندرويد بتقيّد فتح التطبيقات من الخلفية، جرّب تدي التطبيق صلاحية "العرض فوق التطبيقات الأخرى".
- تغيير سطوع الشاشة مش موجود في النسخة دي.
